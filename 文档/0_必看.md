## 一、任务路由（先确定你是哪种任务）

### 🅰 只改书源（book source/*.js，不 build、不 push 代码）

- 看 `references/COMIC_SOURCE_DEV.md`（书源开发全书）
- 唯一提交注意：书源 js 是本地私有内容，**不要 push 进仓库** → `references/GIT_WORKFLOW.md` 第 2.1 节
- **不用看**：`references/BUILD_WINDOWS.md` 等构建文档 —— 书源开发与构建 / 版本号 / CI 无关，跳过
- 不碰 lib/ 代码、不 build exe、不发版 → 不需要了解任何构建知识

### 🅱 改 App 代码（lib/*.dart）+ 要 build Windows exe

- 看 `references/BUILD_WINDOWS.md`（本地构建全流程与坑）
- 提交前看 `references/GIT_WORKFLOW.md` 第 1 节（push 走代理）+ 第 2 节（提交规则）
- 改了阅读器（连续滚动/跨章/prepend）代码，跑测试看 `references/TESTING.md`（E2E + widget，注意要在用户终端跑）
- 可跳过：`references/COMIC_SOURCE_DEV.md`（除非本次改动涉及书源相关代码）

### 🅲 发版 / 打 tag / 手动取 APK / CI 失败排查

- 看 `references/GIT_WORKFLOW.md` 全文（push / 提交 / 跳过 CI / 发版全流程）
- 看 `references/VERSION_RULES.md`（版本号规则，发版必改两处）+ `references/CI_DIAGNOSIS.md`（CI analyze 诊断）
- 可跳过：`references/COMIC_SOURCE_DEV.md`

## 二、通用铁律（所有任务都适用）

- **书源相关内容永不写进根目录 `README.md`**：README 只记 App 功能改动（阅读器、收藏、追更、UI），书源改动记录只写进 `references/` 下文档
- **书源 `.js` 文件不要 push 进主仓库**：本地私有内容，提交时只 `git add` 真正的源码改动，不要 `git add .`
- **输出文件 UTF-8 无 BOM**：所有 `.dart` `.js` `.md` `.txt` 等一律无 BOM

---

## 三、禁止操作（红线，违反会破坏构建环境）

- ❌ **禁删 `pubspec.lock`** —— 重新解析依赖会导致 FRB / transitive deps 全线漂移，不可逆
- ❌ **禁 `flutter clean`** —— 会删整个 `.dart_tool/` 目录（含 `package_config.json`），等效破坏
- ❌ **禁走中国镜像跑 `flutter pub get`**（`PUB_HOSTED_URL=https://pub.flutter-io.cn`）—— 会污染 `package_config.json`，导致 FRB 版本脱节（详见下方常见 bug）
- ❌ **本地禁 build Android APK** —— 本地环境只能出 Windows exe（Gradle daemon 崩溃 + NDK license 缺失），APK 只能走 GitHub Actions CI
- ✅ 任何 `flutter analyze` / `flutter build` 后，若改了 `pubspec.lock`，必须 `git checkout -- pubspec.lock` 还原

## 四、常见 bug 与解决方案（FRB 报错，最高频）

**症状**：
```
DioException [unknown]: null
Error: Bad state: flutter rust bridge has not been initialized.
Did you forget to call await RustLib.init();?
```

**根因**：中国镜像污染。`package_config.json` 被写成指向 `pub.flutter-io.cn/flutter_rust_bridge-2.12.0`，而 `pubspec.lock` 锁的是 2.11.1 → 版本脱节 → **所有网络请求全挂**。

**修复**（两步）：
```bash
rm .dart_tool/package_config.json
unset PUB_HOSTED_URL FLUTTER_STORAGE_BASE_URL
flutter pub get
```
然后 `build-win.bat` 重建 exe。

**预防**：任何 `flutter pub get` 之前必须 `unset PUB_HOSTED_URL FLUTTER_STORAGE_BASE_URL`。

完整诊断步骤（看日志、grep 验证）→ `references/BUILD_WINDOWS.md`
